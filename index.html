Workflow 02 Trigger: Hourly / Manual

Recruitment 2 - Batch Evaluation (AI Screening)

Pulls new pending applications, downloads CVs from Drive, extracts text via OCR & PDF reader, builds candidate profiles, scores candidates using LLMs, and triggers automated emails (Invites/Declines).

Workflow 03 Trigger: Error & Cron

Recruitment 3 - Error Handler & Heartbeat

Catches system failures, classifies error types (auth, network, AI parsing, data bugs), logs them to an error sheet, applies smart email alert throttling, sends daily digests, and monitors queue stagnation.

Global Error Workflow Active Monitoring
